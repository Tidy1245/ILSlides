ILSlides v1.0.8

- 圖片瀏覽支援雙指張開／捏合縮放，兩指一起移動可平移查看區域；單指左右滑動維持上一張／下一張。
- 快速雙擊圖片指定位置可放大，再次雙擊恢復完整圖片。設定頁新增「雙擊放大倍率」，預設 2 倍，可選 1.50～4.00 倍，每格 0.25 倍，自動保存。
- 切圖及淡入淡出保留倍率與相對查看位置；不同尺寸／直橫圖片保持原比例並限制邊界，螢幕旋轉後仍保留視窗。離開再開啟集合時恢復完整圖片。
- 雙指操作中抬起一指不會誤切圖，所有手指放開後才開始下一次單指操作；雙擊與縮放不切換標題列，單擊會等待約 280ms 判定。
- 縮放及平移沿用已解碼的預覽，不修改原始圖片。

下載 ILSlides1-0-8.apk，可覆蓋安裝；Android 9 以上，versionName 1.0.8、versionCode 9，沿用相同 debug 簽章。

驗證：55 項 TypeScript 單元測試、5 項 Android 快取測試、三組手機 UI 回歸通過。Chromium 真實觸控事件涵蓋雙擊指定區域放大／還原、設定保存、雙指縮放／平移、部分抬指與取消、放大時單指切圖、轉場中縮放一致、直橫圖／旋轉位置保持與新集合重設。Android 建置、lint、APK 版本與簽章驗證通過。

UI 原生 bridge、SAF 及圖片使用模擬資料，未接 Android 實機；裝置上的雙指手感及圖片解碼仍需實機驗證。放大沿用目前長邊最多 2048px 的瀏覽預覽。
