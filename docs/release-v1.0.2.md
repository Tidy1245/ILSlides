ILSlides v1.0.2

- 集合封面：從集合選一張圖片，固定 4:3 視窗中拖曳位置、縮放 1～3 倍、重設位置；確認後隨集合儲存，重開保留。
- 移除首頁四行介紹文字。
- 編輯介面底部固定「刪除集合」鍵，確認後刪除集合，保留原始圖片與常用資料夾。
- 新增首頁集合名稱搜尋、清除搜尋與無結果提示。

下載 ILSlides1-0-2.apk，可覆蓋安裝；Android 9 以上，Android versionCode 3，沿用上一版 debug 簽章。

驗證：11 項單元測試、手機 UI 封面選取／拖曳／縮放／取消／保存、搜尋／刪除及既有流程測試、Android 建置及 lint、APK 簽章檢查通過。UI 使用模擬 native bridge，未連接 Android 實機。
