ILSlides v1.0.12

新增與編輯集合時，挑圖搜尋現在可依圖片檔名或子目錄名稱查找。以目錄名稱找到的圖片會顯示相對目錄路徑，方便辨認同名檔案。

若第一張選取圖片的檔名只有數字，自動命名會採用該圖片所在目錄的名稱，例如 `蘋果/0.jpg` 會命名為「蘋果」。手動輸入的集合名稱仍優先。

Android 9（API 28）以上，versionName 1.0.12、versionCode 13。App 僅讀取授權目錄，不修改來源圖片。

驗證：67 項 TypeScript、12 項 Android 單元測試、正式建置、APK 建置與 lint，以及瀏覽器模擬的新增／編輯集合、目錄搜尋和自動命名流程。未接 Android 實機；瀏覽器驗證的原生 bridge 使用模擬資料。
