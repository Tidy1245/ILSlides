ILSlides v1.0.14

新增與編輯集合改為兩頁：第一頁挑選圖片，可搜尋、排序、跨資料夾選取與拖曳已選圖片；第二頁設定集合名稱、標籤與封面。第一頁底部按鈕改為「下一步」，第二頁才建立或儲存集合。

兩頁可點步驟或左右滑動切換，並以水平動畫轉場。切頁保留選取內容與各頁捲動位置；滑動不干擾已選圖片的長按拖曳及資料夾橫捲。

Android 9（API 28）以上，versionName 1.0.14、versionCode 15。App 僅讀取授權目錄，不修改來源圖片。

驗證：69 項 TypeScript、12 項 Android 單元測試、正式建置、APK 建置與 lint；手機尺寸瀏覽器驗證雙頁轉場、切頁保存、挑圖搜尋／排序、封面及既有集合操作。瀏覽器原生 bridge 使用模擬資料，未接 Android 實機。
