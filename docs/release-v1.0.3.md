ILSlides v1.0.3

- 固定頂部列，右側齒輪開啟設定頁；版本號移至設定頁。
- 設定頁提供圖片轉場滑桿：0.10～2.00 秒，預設 0.36 秒，設定自動保存。
- 固定底部導覽改為左側首頁、右側集合。
- 首頁最多顯示最近修改的 4 筆集合。
- 集合頁提供完整管理、搜尋與封面功能；新增字母／建立日期／修改日期排序，各支援遞增及遞減。
- 新建及編輯記錄日期；舊集合缺少歷史日期時顯示「未記錄」。
