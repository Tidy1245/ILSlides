ILSlides v1.1.0

- 新增／編輯集合的資訊頁底部可勾選「焦點集合」，集合卡片橫跨兩欄，封面調整使用較寬的 8:3 比例；一般集合維持 4:3。
- 封面未設定時顯示土黃色三角驚嘆號，點「使用此封面」後顯示綠色圓形勾，隨建立／儲存集合保存。取消調整不會標記為已設定，舊自訂封面沿用已設定狀態。
- 切換焦點勾選時，新比例顯示未設定；同一次編輯切回原勾選狀態可恢復原裁切與圖示。
- 有焦點集合時，「為你推薦」首筆隨機選焦點，再從其餘集合隨機挑選最多四筆，集合不重複；無焦點時維持四筆推薦。
- 篩選新增「只顯示焦點集合」，可與名稱搜尋、標籤及排序共同套用；支援取消與重設。

Android 9（API 28）以上，versionName 1.1.0、versionCode 17。App 僅讀取授權圖片，不修改原始檔。

驗證：77 項 TypeScript、12 項 Android 單元測試、正式建置、APK 與 lint；7 組手機尺寸瀏覽器流程包含新焦點功能、封面、快取、標籤、挑圖拖曳及集合編輯回歸。瀏覽器原生 bridge 使用模擬資料，未接 Android 實機。
