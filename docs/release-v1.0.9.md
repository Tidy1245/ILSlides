ILSlides v1.0.9

- 「選擇／重新授權資料夾」移至設定頁「圖片資料夾」，可查看已授權來源。新增與編輯集合保留常用資料夾切換。
- 挑圖區加入與集合頁相同樣式的檔名搜尋與漏斗按鈕；排序視窗僅提供檔名／修改日期的遞增、遞減排序，獨立保存，不影響已選圖片順序。沒有修改日期的圖片排在最後。
- 搜尋後可全選搜尋結果；跨資料夾選取保留，切換資料夾時清除搜尋。
- 已選圖片長按約 450ms 可拖曳調整順序，移至兩側自動捲動；短按移除，一般滑動捲動清單。取消手勢、Escape 或 Android 返回會撤銷當次拖曳。建立與編輯儲存後依新順序瀏覽，自動命名依新的第一張圖片決定。

下載 ILSlides1-0-9.apk，可覆蓋安裝；Android 9 以上，versionName 1.0.9、versionCode 10，沿用相同 debug 簽章。

驗證：62 項 TypeScript 單元測試、5 項 Android 快取測試、4 組手機 UI 回歸、Android 建置與 lint、APK 版本與簽章檢查通過。新增 Chromium 真實觸控事件驗證前後拖曳、邊緣自動捲動、一般滑動／短按、取消、建立與編輯順序保存及圖片瀏覽順序。

UI 原生 bridge、SAF 與圖片使用模擬資料，未接 Android 實機；裝置持久授權、圖片修改日期及長按拖曳手感仍需實機確認。App 不修改來源圖片。
