ILSlides v1.0.5

- 編輯集合也提供半透明回頂部按鈕，捲動離開頂部時出現。
- 新集合名稱留空時，自動採第一張選取圖片檔名，依 ^([^s-]+) 取第一個空白或 - 前的字串。
- 例：旅行-001.jpg、旅行 001.jpg → 旅行；沒有分隔符時保留完整檔名，包含副檔名。
- 設定頁新增「自動命名新集合」開關，預設啟用並自動保存。手動名稱優先，已有集合不自動改名。

下載 ILSlides1-0-5.apk，可覆蓋安裝；Android 9 以上，versionName 1.0.5、versionCode 6，沿用相同 debug 簽章。
