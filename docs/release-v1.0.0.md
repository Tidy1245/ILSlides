ILSlides 第一版：手機本機圖片集合瀏覽器。

- 藍黑色漸層、簡約圓角卡片、繁體中文介面。
- 自訂多個集合與集合名稱，各集合指定裝置上的圖片目錄。
- 系統目錄選擇器與持久讀取授權，原始圖片不搬移、不修改、不上傳。
- 左右滑動／箭頭循環瀏覽，360ms 淡入淡出，預先解碼與下一張預讀。
- 沉浸瀏覽、重新讀取目錄、集合編輯與移除。

安裝：下載 ILSlides1-0-0.apk，於 Android 9 以上手機開啟安裝。
使用：新增集合 → 輸入名稱 → 選擇目錄並授權 → 開始瀏覽。

與 Video-Box 相同，提供 Capacitor debug 簽章 APK，供直接安裝。

驗證：前端型別檢查／建置、3 項單元測試、390 × 844 手機 UI 自動測試、Android APK 建置及簽章檢查通過。UI 測試使用模擬原生 bridge；此次未連接 Android 實機，目錄授權與實際圖片解碼仍需裝置確認。

目前讀取所選目錄內圖片（不含子目錄）；GIF 使用靜態預覽，支援格式依裝置解碼器而定。Android 系統限制部分根目錄的選取，請選一般圖片子目錄。
