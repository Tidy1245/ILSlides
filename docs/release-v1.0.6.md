ILSlides v1.0.6

- 封面接近畫面才載入，首頁優先處理最近 4 筆，不再依序重建所有集合封面。
- 新增 Android 私有封面縮圖快取，重新開啟直接顯示；背景檢查原圖變動，遺失或損壞時自動重建。快取上限 64 MiB，設定頁可點「重新整理封面」。
- 設定頁可新增、修改及刪除標籤，並自訂漸層起始色與結束色。
- 新增／編輯集合可加入多個標籤；首頁與集合頁在名稱下方顯示標籤，取代原說明／日期文字。日期資料仍保留供排序使用。
- 修改標籤會同步反映在所有相關集合；刪除標籤只解除標籤參照，保留集合與圖片。
