ILSlides v1.0.1 修正集合與資料夾的使用方式。

- 常用資料夾作為快速找圖捷徑，App 記住已授權的位置。
- 從縮圖勾選多張圖片建立集合，可跨資料夾挑選。
- 編輯集合可改名、增加圖片或取消已選圖片；集合各自保存。
- 資料夾新增圖片不會自動加入集合。
- 舊版集合保留名稱並轉成固定圖片清單，原目錄保留為捷徑。
- 發布預設 patch 版號自動 +1，除非使用者指定；本次為 1.0.1、Android versionCode 2。

下載 ILSlides1-0-1.apk，直接覆蓋安裝；支援 Android 9 以上，使用與上一版相同的 debug 簽章。
使用流程：新增集合 → 輸入名稱 → 選擇常用資料夾 → 勾選圖片 → 建立集合。

驗證：6 項單元測試、手機 UI 多選／保存／編輯／跨資料夾／舊版轉換測試、Android 建置與 lint、APK 簽章驗證通過。UI 使用模擬原生 bridge；未連接 Android 實機，目錄授權與裝置解碼仍需實機確認。
