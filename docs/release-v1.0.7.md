ILSlides v1.0.7

- 離開圖片瀏覽後，回到原本的首頁／集合頁捲動位置，保留搜尋與標籤條件；支援畫面返回、Android 返回鍵與 Escape。
- 搜尋框右側新增漏斗按鈕，移除原本的整列排序控制，改由「篩選與排序」視窗操作。
- 保留字母、建立日期與修改日期各自的遞增／遞減排序，並保存排序選擇。
- 支援複選標籤篩選，符合任一所選標籤即顯示，並可與集合名稱搜尋搭配；不選標籤時顯示全部。
- 按「套用篩選」才生效；可重設條件，關閉或返回則取消尚未套用的修改。漏斗會顯示已選標籤數量。

下載 ILSlides1-0-7.apk，可覆蓋安裝；Android 9 以上，versionName 1.0.7、versionCode 8，沿用相同 debug 簽章。

驗證：38 項 TypeScript 單元測試、5 項 Android 快取測試、既有手機 UI 回歸與篩選／排序／搜尋／標籤組合、取消／重設、首頁及集合頁返回位置流程通過。Android 建置、lint、APK 版本與簽章驗證通過。

UI 原生 bridge、SAF 及圖片使用模擬資料，未接 Android 實機。
